# 项目优化路线图 (Roadmap)

基于对当前项目的分析，以下是分阶段的优化建议与实施计划。

## 1. 工程化与稳定性 (优先级：高)

这些改进将确保项目的长期稳定运行和易于维护。

- [ ] **补充单元测试**
    - 目标：确保核心算法（艾宾浩斯复习逻辑）的正确性。
    - 行动：在 `tests/` 目录下创建针对 `WordSelectorV2` 的测试用例。
    - 工具：`unittest` 或 `pytest`。

- [x] **Docker 化部署**
    - 目标：统一开发与生产环境，简化部署流程。
    - 行动：创建 `Dockerfile` 和 `docker-compose.yml`。
    - 收益：不再依赖本地 Python 环境，一键启动。

- [x] **日志与监控**
    - 目标：及时发现运行故障（如邮件发送失败）。
    - 行动：集成简单的报警机制（如 Server酱、钉钉机器人），当 `main.py` 运行出错时发送通知。

## 2. 代码与架构优化 (优先级：中)

这些改进将提升代码质量和性能。

- [x] **数据存储升级 (SQLite)**
    - 目标：解决 JSON 文件随时间增长带来的性能和数据损坏风险。
    - 行动：将 `word_history.json` 迁移至 SQLite 数据库。
    - 收益：支持更复杂的查询（如按掌握度筛选），数据更安全。

- [x] **路径与配置管理优化**
    - 目标：消除硬编码路径，增强配置安全性。
    - 行动：
        - 使用 `pathlib` 替代 `os.path` 进行路径操作。
        - 引入 `python-dotenv`，支持从 `.env` 文件读取敏感配置（如邮箱密码）。

## 3. 功能增强 (优先级：低)

这些改进将提升用户体验。

- [x] **Web 端交互增强**
    - 目标：从"只读"统计变为"可交互"学习。
    - 行动：
        - 在邮件中添加"认识/不认识"链接，点击直接更新数据库。
        - Web 界面增加单词管理功能（手动添加生词、屏蔽单词）。

- [x] **多词库支持**
    - 目标：支持用户自定义学习内容。
    - 行动：重构 `WordParser`，支持导入 CSV/Excel 文件，支持多词书切换。

- [ ] **AI 内容增强**
    - 目标：增加学习趣味性。
    - 行动：接入 LLM API，为单词动态生成趣味短文或助记提示。
