# Python 学习大纲

## 第一阶段：基础入门

### 1. 环境搭建
- Python 安装与配置
- IDE 选择（VS Code / PyCharm）
- pip 包管理工具

### 2. 基础数据类型
- 整数（int）
- 浮点数（float）
- 字符串（str）
- 布尔值（bool）
- None 类型

### 3. 数据结构
- 列表（list）：增删改查、切片、排序
- 元组（tuple）：不可变序列
- 字典（dict）：键值对操作
- 集合（set）：并集、交集、差集、对称差集

### 4. 运算符
- 算术运算符：`+` `-` `*` `/` `//` `%` `**`
- 比较运算符：`==` `!=` `>` `<` `>=` `<=`
- 逻辑运算符：`and` `or` `not`
- 成员运算符：`in` `not in`
- 身份运算符：`is` `is not`

### 5. 流程控制
- 条件语句：`if` `elif` `else`
- 循环语句：`for` `while`
- 循环控制：`break` `continue` `pass`
- 列表推导式

---

## 第二阶段：函数与模块

### 6. 函数
- 函数定义与调用
- 参数类型：位置参数、默认参数、可变参数（`*args`、`**kwargs`）
- 返回值
- 匿名函数（lambda）
- 作用域（局部变量、全局变量）
- 递归函数

### 7. 内置函数
- 常用函数：`len()` `range()` `enumerate()` `zip()` `map()` `filter()` `sorted()`
- 类型转换函数：`int()` `str()` `list()` `dict()` `set()` `tuple()`

### 8. 模块与包
- 模块导入：`import` `from...import`
- 常用标准库：`os` `sys` `math` `random` `datetime` `json`
- 第三方库安装与使用
- 自定义模块与包

---

## 第三阶段：面向对象编程（OOP）

### 9. 类与对象
- 类的定义与实例化
- 属性与方法
- 构造方法 `__init__`
- `self` 关键字

### 10. 面向对象特性
- 封装
- 继承（单继承、多继承）
- 多态
- 方法重写

### 11. 高级特性
- 类属性与实例属性
- 类方法与静态方法（`@classmethod` `@staticmethod`）
- 私有属性与方法
- 魔术方法：`__str__` `__repr__` `__len__` `__eq__` 等

---

## 第四阶段：文件与异常处理

### 12. 文件操作
- 文件读写：`open()` `read()` `write()` `close()`
- 上下文管理器：`with` 语句
- 文件模式：`r` `w` `a` `rb` `wb`
- CSV / JSON 文件处理

### 13. 异常处理
- `try` `except` `else` `finally`
- 常见异常类型
- 自定义异常
- `raise` 抛出异常

---

## 第五阶段：高级进阶

### 14. 迭代器与生成器
- 可迭代对象
- 迭代器：`__iter__` `__next__`
- 生成器：`yield` 关键字
- 生成器表达式

### 15. 装饰器
- 闭包
- 函数装饰器
- 带参数的装饰器
- 类装饰器

### 16. 正则表达式
- `re` 模块
- 常用方法：`match()` `search()` `findall()` `sub()`
- 正则语法：`.` `*` `+` `?` `[]` `^` `$` `\d` `\w` `\s`

### 17. 多线程与多进程
- `threading` 模块
- `multiprocessing` 模块
- 线程同步与锁
- 线程池与进程池

---

## 第六阶段：实战应用

### 18. 网络编程
- HTTP 请求：`requests` 库
- 爬虫基础：`BeautifulSoup` `Scrapy`
- API 调用与解析

### 19. 数据库操作
- SQLite / MySQL / PostgreSQL
- ORM 框架：`SQLAlchemy`
- 数据库 CRUD 操作

### 20. Web 开发
- Flask 框架入门
- Django 框架入门
- RESTful API 设计

### 21. 数据分析与可视化
- NumPy 数组操作
- Pandas 数据处理
- Matplotlib / Seaborn 可视化

### 22. 自动化脚本
- 文件批量处理
- 定时任务
- 办公自动化（Excel / Word / PDF）

## 学习建议

1. **多动手**：每学一个知识点，写代码实践
2. **做项目**：从小项目开始，逐步提升
3. **看源码**：阅读优秀开源项目
4. **写笔记**：整理学习笔记，加深记忆
5. **坚持**：每天保持学习，持续进步
