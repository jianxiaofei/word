## 🔍 算法工作流程

### 新单词学习

```
1. 从数据库获取未学单词
     ↓
2. 设置初始状态
   - status = 1 (学习中)
   - mastery_level = L0
   - review_count = 0
   - first_learned = 今天
   - next_review = 今天 + 1天
     ↓
3. 写入数据库
```

### 复习标记流程

```
用户复习单词
     ↓
标记"认识" ───→ mark_reviewed()
     ↓             ├─ review_count + 1
     │             ├─ mastery_level + 1
     │             ├─ last_review = 今天
     │             └─ next_review = 今天 + INTERVALS[新等级]
     ↓
更新数据库

标记"不认识" ─→ mark_unknown()
                 ├─ review_count + 1
                 ├─ mastery_level = 0 (重置)
                 ├─ last_review = 今天
                 └─ next_review = 今天 + 1天
```

### 每日单词选择

```
1. 获取到期复习单词
   WHERE next_review <= 今天
   AND status = 1
     ↓
2. 如果超过限制，随机选择N个
     ↓
3. 获取新单词 (status = 0)
     ↓
4. 组合返回: 新词 + 复习词
```

```python
def mark_reviewed(self, word_id: int):
    new_review_count = record['review_count'] + 1
    new_mastery_level = min(new_review_count, len(self.REVIEW_INTERVALS) - 1)
    next_interval = self.REVIEW_INTERVALS[new_mastery_level]
    next_review = (today + timedelta(days=next_interval)).isoformat()
```

def get_words_for_review(self, due_date: str) -> List[Dict]:

## 📚 理论依据

### 艾宾浩斯遗忘曲线

德国心理学家赫尔曼·艾宾浩斯(Hermann Ebbinghaus, 1850-1909)通过实验发现：

> "记忆的保持随时间呈指数衰减，通过在关键时间点复习，可以显著提高长期记忆效果。"

### 间隔重复学习 (Spaced Repetition)

研究表明，相比集中学习(Massed Practice)，间隔学习(Spaced Practice)能提高：
- **长期记忆** 提升 50-200%
- **学习效率** 提高 30-80%
- **遗忘速度** 降低 60-90%
